# Sicherheit

Die Website ist statisch (HTML, CSS, JavaScript, Bilder) und verarbeitet keine Formulardaten auf dem Server.

**Schwachstelle gefunden?** Bitte nicht als öffentliches Issue melden, sondern vertraulich über GitHub:
Reiter **Security** → **Report a vulnerability** (private Schwachstellenmeldung ist aktiviert).

Abhängigkeiten werden über Dependabot überwacht (Sicherheitsupdates und wöchentliche Versionsupdates).
